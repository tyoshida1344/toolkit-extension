# 撮り方のこつ

画面のエビデンスを Playwright で撮る時に、つまずきやすいところ。Playwright を自分のスクリプトから動かす時も、Playwright MCP から動かす時も同じ。
撮る手立ては使うプロジェクトで決める。ここに無いこつは、写した先で書き足す。

この拡張機能では、[../scripts/extension-harness.mjs](../scripts/extension-harness.mjs) が次のいくつかを引き受けている(拡張機能の読み込み、1項目1ページ、動画を止める前の待ち、画面のエラーを集める)。使い方は SKILL.md の手順3。

## どれにも共通

- **画面の大きさを揃える。** 例えば 1280×720。揃えないと、ビューアで並べた時に幅が散る。撮り直す時はとくに気をつける(Playwright MCP は `browser_resize` で揃える。忘れるとウィンドウの大きさで撮れる)
- **結果が画面に出てから撮る。** 押した直後に撮ると、変わる前の画面が残る。待つ時は、時間ではなく結果の要素が出るのを待つ
- **1項目につき1ページ(1タブ)にする。** 前の項目の状態を持ち越さない。書きかけの入力を残したまま次へ移ると、画面を離れる時の確認(`beforeunload`)が出て止まることがある。項目の終わりに確認へ答え、空のページへ移しておく
- **ブラウザが描く確認や通知は、画像にも動画にも映らない。** 出たかどうかは、Playwright の `dialog` の出来事(MCP なら返答の「Modal state」)で見て、`checks` に書く
- **ログインが要る時は、その場で作ったテスト用のアカウントを使う。** 利用者本人のアカウントは使わない
- 失敗した時の表示を確かめる項目は、`page.route` で通信を失敗させて起こす(サーバーを止めない)

## 動画

- **録画はページを開いてから始める。** ページの無い状態で始めると失敗する(Playwright MCP の `browser_start_video`)。スクリプトなら、項目ごとに新しいページを開いて録画し、閉じた時に保存する
- **何の確認かを動画に残す。** Playwright MCP なら `browser_video_chapter` の `title` に受入確認の文言をそのまま入れる。スクリプトなら、画面の隅に文言を出しておく
- **結果が出たら1秒ほど待ってから止める。** すぐ止めると、結果が映らないまま終わる。操作が速すぎると、1コマも残らず保存に失敗することもある
- 機械で判定できない項目(矢印の向き・動き)は、動画のコマを切り出して目で確かめてから○にする
- 1本は短くする。上げ方によっては大きさに上限がある

## 画像

- **見えている範囲だけを撮る。** 結果が画面の外にある時だけページ全体を撮る
- 端末の倍率に左右されないよう、CSS の大きさで撮る(Playwright MCP は `scale: "css"`)
- 画像には何の確認かが書かれていない。`checks` に、画面のどこを見て○にしたかを書く

## 入力

- **日本語入力の変換中は、本当に変換中の状態を作る。** 変換中を表すイベントを送るだけでは、画面に変換中の文字が出ず、エビデンスにならない。CDP のセッション(`page.context().newCDPSession(page)`)で、`Input.imeSetComposition`(変換中の文字)→ `Input.dispatchKeyEvent`(変換中のキー)→ `Input.insertText`(確定)/ 空の `Input.imeSetComposition`(取り消し)の順に送る。変換中かどうかは動画では見分けにくいので、`compositionstart` / `compositionend` と `keydown` の `isComposing` を画面の隅に出しておく
- 文字をまとめて入れるなら `keyboard.insertText`、キーの1つずつの動きを確かめるなら `keyboard.press`

## 端末を変える

- タッチやスマートフォンの幅の項目は、端末を指定して撮る(スクリプトなら `devices['iPhone 15']` で新しいコンテキストを作る。Playwright MCP なら端末を指定した別のサーバーを `--device "iPhone 15" --isolated` で立てる。`--isolated` が無いと、同じブラウザのプロフィールを取り合って起動できない)。ログインはそちらでやり直す

## スクリプトで動かす時(Node)

- Windows で絶対パスのモジュールを `import` する時は、`file:///C:/...` の形で書く
- ブラウザの拡張機能を読み込んで撮る時は、`chromium.launchPersistentContext` に `channel: 'chromium'` と `--disable-extensions-except` / `--load-extension` を渡す(Chrome 本体は `--load-extension` を受け付けない)。拡張機能の ID は、サービスワーカーの URL から取れる
- 撮り終えても子のプロセスが残り、Node が終わらないことがある。スクリプトの最後で `process.exit(0)` する
